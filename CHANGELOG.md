# Changelog

## 1.1.0 — 2026-11-01

- Document and use the standalone knvtop-service dependency; the Plasma widget is no longer required.
- Show a clear unavailable state when the shared D-Bus daemon is not installed or running.

## 1.0.0 — 2026-11-01

- First public release of the onvtop OpenChamber extension.
- Add GPU/GTT-focused rail panel and compact Work Status graph using knvtop's D-Bus service.
- Add persistent graph-line toggles and shared/system memory readouts.
